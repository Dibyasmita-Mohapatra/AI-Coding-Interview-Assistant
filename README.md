# 📌 Overview

AI Interview Assistant is a full-stack web application designed to help students and job seekers prepare for technical interviews using AI.

Users can:

- Practice Coding Interviews
- Practice HR Interviews
- Analyze Resume Quality
- Build Professional ATS-Friendly Resumes
- Match Resume Against Job Descriptions
- Track Previous Interview Performance

The project is built using the MERN Stack with AI integration.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/ai-interview-assistant.git
```

---

## Frontend

```bash
cd client
npm install
npm run dev
```

---

## Backend

```bash
cd server
npm install
npm start
```

---

# 🔑 Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000

MONGODB_URI=YOUR_MONGODB_CONNECTION_STRING

JWT_SECRET=YOUR_SECRET_KEY

OPENAI_API_KEY=YOUR_OPENAI_API_KEY
```

> **Do not commit your `.env` file to GitHub.**
